# O que é o DOM?

O **DOM (Document Object Model)** é a representação do HTML em forma de **árvore**.

Isso permite que o JavaScript:

- Leia lementos da página
- Modifique textos
- Troque imagens
- Reaja a cliques
- Crie elementos novos

> O navegador transforma o HTML em objetos manipuláveis.
