# JavaScript - Resumo

## História

📖 O que é JavaScript?

JavaScript é uma linguagem de programação criada em 1995 por Brendan Eich, inicialmente para adicionar interatividade às páginas Web. Com o passar dos anos, tornou-se uma das principais tecnologias do desenvolvimento de software.

🕐 História
1995: JavaScript é criado para o navegador Netscape.
1997: A linguagem é padronizada pela ECMA e passa a ser especificada como ECMAScript.
2009: Surge o Node.js, permitindo executar JavaScript fora do navegador.
2015: O ECMAScript 6 (ES6) traz importantes melhorias para a linguagem.
Atualmente: JavaScript é usado em Web, servidores, aplicativos, desktop, jogos e outras aplicações.
🌐 Importância no desenvolvimento Web

O desenvolvimento Web utiliza principalmente:

HTML       → Estrutura
CSS        → Estilo
JavaScript → Interatividade e comportamento

JavaScript permite criar páginas e aplicações dinâmicas, como formulários, menus, animações, dashboards e sistemas completos.

🚀 Conclusão

JavaScript começou como uma linguagem para tornar páginas Web mais interativas e evoluiu para um dos principais ecossistemas de desenvolvimento de software.

Hoje, sua importância está principalmente na versatilidade, podendo ser utilizada no Front-end, Back-end, mobile, desktop, jogos e cloud.

JavaScript: de uma linguagem criada para o navegador a uma tecnologia fundamental para o desenvolvimento moderno.
